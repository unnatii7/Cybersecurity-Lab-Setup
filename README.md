# Cybersecurity-Lab-Setup
Cybersecurity Lab Setup
🐉 Kali Linux Cybersecurity Lab

A personal cybersecurity practice lab set up using Kali Linux to explore security tools, Linux fundamentals, networking, web security, and ethical hacking concepts.

🎯 Objectives

- Build a hands-on cybersecurity practice environment
- Learn and explore commonly used security tools
- Practice Linux commands and networking concepts
- Understand basic reconnaissance and vulnerability assessment
- Develop practical skills alongside academic cybersecurity studies

🖥️ Lab Environment

- OS: Kali Linux
- Platform: VirtualBox
- Purpose: Cybersecurity learning and authorized testing
- Network: NAT-based lab environment

🛠️ Tools & Technologies

Some of the tools being explored in this lab include:

- Nmap — Network scanning and enumeration
- Burp Suite — Web application security testing
- Wireshark — Network traffic analysis
- Metasploit Framework — Security testing and exploitation in controlled environments
- OWASP ZAP — Web application security testing
- John the Ripper — Password security testing
- SQLmap — SQL injection testing in authorized environments

🧪 Practice Areas

This lab will be used for hands-on learning in areas such as:

- Linux fundamentals
- Networking
- Reconnaissance
- Web application security
- Vulnerability assessment
- Password security
- Network traffic analysis
- Ethical hacking

📚 Learning Approach

The lab is intended for educational and authorized security testing only. Experiments will be performed on systems that I own or have explicit permission to test.
